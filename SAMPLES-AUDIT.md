# Foundgine Samples Audit — Pass 2

## Scope

Reviewed C# and Java sample projects, provider gateway examples, Temporal/Keycloak integration sketches, project/module/solution references, sample READMEs, and references in repository README, docs and docs-site. This is a static review of the uploaded ZIP snapshot. Full builds were not possible in this environment: the .NET SDK and Maven are not installed, and the available Java runtime is 21 while the Java samples document a newer JDK requirement.

## Actions completed

### Removed stale starter tutorials

The C# starter README explicitly said its tutorial and companion explanation described an earlier SQL-provider/ERP-storage architecture. The Java starter README explicitly said its tutorials described the old annotation-based implementation. Removed these four misleading documents and replaced their references with the maintained sample READMEs:

- `src/csharp/samples/Foundgine.SupplyChain/SupplyChain-Starter-Tutorial.md`
- `src/csharp/samples/Foundgine.SupplyChain/Foundgine-SupplyChain-Explained.md`
- `src/java/samples/foundgine-supply-chain/SupplyChain-Starter-Tutorial.md`
- `src/java/samples/foundgine-supply-chain/Foundgine-SupplyChain-Explained.md`

Updated root README, `docs/GETTING-STARTED.md`, docs-site Markdown/HTML getting-started and sample pages to stop linking to deleted tutorials. The current starter README is the authoritative entry point.

### Removed generated/IDE artifacts

- Java starter and advanced `.project` files (Eclipse metadata).
- Java starter and advanced `.flattened-pom.xml` outputs generated by the Maven flatten plugin.
- Added `.flattened-pom.xml` to `.gitignore`.

### Clarified Temporal sample status

Added `src/csharp/samples/Foundgine.Extensions.Temporal/README.md` to classify the API and Worker as integration sketches, not runnable standalone hosts. Updated the Temporal extension README's local-development section to stop implying that the incomplete sample can be run directly. Removed the hard-coded development `ServiceClientSecret` from the Worker appsettings; set it through environment/secret configuration instead.

Updated `src/csharp/samples/README.md` to list the starter, advanced and Temporal integration sketch, and to point to provider samples.

## Files deliberately retained

- `src/csharp/samples/Foundgine.SupplyChain.Advanced/reports/*`: runner/publish scripts and README refer to generated report outputs. They may be stale captured evidence, but the publication workflow needs a separate decision about whether generated reports are versioned.
- `src/java/samples/*/src/main/foundgine/migrations/*`: schema snapshots/history and generated migrations are source inputs for the sample migration workflow, not disposable build output.
- `MCP.Foundgine`, `Agent`, and `Database` in the advanced C# sample: included in its solution and Docker/run scripts; not orphan projects.
- Gateway examples: kept as distinct foundation/minimal-host learning steps.

## Remaining modernization candidates

1. Verify Java starter and advanced sample compilation/runtime against the current Java provider/JPA implementation.
2. Verify Java Gateway Minimal API and Gateway Foundation sample compilation; their code/docs should be aligned with the latest gateway contracts.
3. Decide whether the advanced C# checked-in `reports/` outputs are intentionally committed evidence or should be generated locally and ignored.
4. Turn the Temporal sketch into a complete runnable sample (compose, host registrations, secrets, end-to-end test) or remove it if the project no longer intends to support a demonstration.
5. Check docs-site sample navigation and HTML against the updated README destinations.

## Additional findings

- The C# advanced sample contains a benchmark-oriented host and a separate `Semantic/` solution. The root `MCP.Foundgine`, `Agent`, `Database`, Docker Compose and runner are composed for the stochastic E2E workload; the `Semantic/` solution is separately built/tested by CI and contains its MCP API, tests and benchmark project. Both paths remain referenced, so neither was deleted. The README now calls out that they are distinct paths and that benchmark results should not be treated as proof for the other path.
- The Java provider contains two gateway examples: a minimal HTTP host and a dependency-free foundation sample. They are distinct learning steps, not confirmed duplicates.
- The sample-site inventory was updated to include the four Supply Chain samples and the Temporal integration sketches, and the starter links now lead to current READMEs.
- The Temporal sketch's worker appsettings no longer contains a committed development client secret.
