# Foundgine Java samples

The Java Supply Chain path has two maintained entry points: a starter application and an advanced proving ground.

| Sample | Purpose | Start with |
|---|---|---|
| [`foundgine-supply-chain`](./foundgine-supply-chain/README.md) | Starter: fluent semantic/persistence model, JPA/Hibernate, PostgreSQL, authorization and schema migrations. | [README](./foundgine-supply-chain/README.md) |
| [`foundgine-supply-chain-advanced`](./foundgine-supply-chain-advanced/README.md) | Advanced: semantic authorization, mutation, MCP, PostgreSQL and adversarial tests. | [README](./foundgine-supply-chain-advanced/README.md) · [Advanced tutorial](./foundgine-supply-chain-advanced/SupplyChain-Advanced-Tutorial.md) |

The starter's previous annotation-based tutorials were removed because they no longer matched its fluent model. The README is the current maintained guide. The advanced tutorial remains, but its build/run instructions need validation against the current reactor.

See [`../csharp/samples/README.md`](../csharp/samples/README.md) for the C# sample path.
