# SupplyChain benchmark implementation review

Date: 2026-11-17

## Scope reviewed

This review overlays `foundgine-perf-supplychain-increment.zip` onto the uploaded Foundgine repository and uses the uploaded `Foundgine-e2e-example(1).zip` as an integration-pattern reference. The CRM/ERP example is not copied into the SupplyChain benchmark domains.

## Confirmed implementation foundations

- C#: `src/csharp/Foundgine.Providers.EntityFrameworkCore` exists.
- C#: `src/csharp/samples/Foundgine.SupplyChain` contains the SupplyChain domain model, fluent semantic/persistence configuration, EF context configuration, and an existing migration set.
- C#: `src/csharp/Foundgine.Extensions.GraphQL` contains the Hot Chocolate semantic adapter and secure query execution entry points.
- Java: `src/java/foundgine-providers` contains the JPA provider.
- Java: `src/java/foundgine-migrations` contains the metadata-driven migration generator and Flyway integration path.
- Java: `src/java/foundgine-extensions` contains the GraphQL semantic adapter and query/mutation executors.
- E2E reference: CRM has EF migrations and Keycloak identity setup; ERP has Spring Security JWT resource-server configuration, caller/authorization types, JPA integration, and Flyway migrations.

## Required applications still absent

The compose file and `docs/SUPPLYCHAIN-ARMS.md` refer to these four application directories, which are not present in the uploaded repository:

- `src/csharp/benchmarks/SupplyChain.Performance/HotChocolate.SupplyChain.BenchmarkApi`
- `src/csharp/benchmarks/SupplyChain.Performance/Foundgine.SupplyChain.BenchmarkApi`
- `src/java/benchmarks/supply-chain/spring-baseline`
- `src/java/benchmarks/supply-chain/foundgine`

The C# normal arm must use Hot Chocolate + plain EF Core. The C# Foundgine arm must use the Foundgine EF Core provider and its own EF migration set. The Java normal arm must use Spring GraphQL + JPA/Hibernate and its own standard Flyway migration. The Java Foundgine arm must use the Foundgine JPA provider and migration SQL generated by `foundgine-migrations`, applied by Flyway.

## Existing benchmark contracts preserved

- The SupplyChain domain scenarios and vectors remain in `tools/foundgine-perf/scenarios`.
- The four-arm compose contract and separate database names remain unchanged.
- The Keycloak realm generator defines one issuer/audience and the test identities used by the vectors.
- The schema dump and migration-provenance checks remain the required gates.
- CRM/ERP entities are not substituted for SupplyChain entities.
