# The Semantic Execution (SES) standard

Foundgine's architecture is specified independently of this repository's
implementation, as the **Semantic Execution System (SES)** standard, under
[`standards/semantic-execution/`](https://github.com/CristianBarragan/Foundgine/tree/main/standards/semantic-execution)
in the repository. The standard is the authority: where this implementation
and the standard differ, the implementation is incomplete until it either
conforms or the standard is deliberately amended.

Start with the
[standard index](https://github.com/CristianBarragan/Foundgine/blob/main/standards/semantic-execution/README.md),
which links every SES-0## document, the conformance-testing series
(SES-100–SES-105), and the machine-readable gap registry at
`standards/semantic-execution/conformance/known-gaps.json`.

This page lives under `docs/` (and therefore in the mkdocs nav) because the
`standards/` directory itself sits outside `docs_dir` and isn't rendered by
this site; use the links above to reach the standard's actual text.
